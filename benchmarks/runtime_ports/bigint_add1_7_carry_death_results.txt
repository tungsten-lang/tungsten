CHANGE

The separately committed exact seven-limb checkpoint ran C's unconditional
`adds` plus six-`adcs` chain.  This native-only follow-up preserves all upfront
loads, publication stores, allocation, growth, and result representation, but
branches after limb one:

  common: carry is dead; publish all seven registers and return zero
  rare:   propagate through limbs 2..6, publish all seven, return final carry

Carry can survive limb one only when that limb is UINT64_MAX.  Because all
seven inputs were loaded before the first write, both paths preserve the C
leaf's alias safety.  The linked leaf has no frame or nested call.
