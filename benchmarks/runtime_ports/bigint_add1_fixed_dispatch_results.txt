SCOPE

The exact 2x1, 3x1, and 4x1 arithmetic/storage leaves remain unchanged.  This
separate native-only follow-up replaces their repeated `an == N && bn == 1`
tests with one `bn == 1` gate and a compact source `case an` selector:

  1       -> unchanged C w_bigint_add boundary
  2,3,4   -> separately checkpointed exact native leaves
  default -> unchanged C w_bigint_add boundary

Final AArch64 lowering is a compact comparison tree, not a jump table.  The
default preserves every unported word-width route.  No arithmetic, allocation,
growth, normalization, or ownership policy changes in this checkpoint.
