BIGINT POSITIVE TWELVE-BY-TWELVE-LIMB MULTIPLY — EXACT SOURCE CHECKPOINT
============================================================================

Scope
-----

This checkpoint ports only the distinct, raw-positive-header, positive
twelve-by-twelve-limb arm from `bigint_mul_any_routed` /
`bigint_mul_positive_equal`. Native Tungsten preserves C's exact
`bn_mul_eq12` decomposition:

  - the same capacity-thirty-two hot allocation;
  - row zero calls the unchanged tuned `bn_mul_1_f12` primitive;
  - rows one through eleven call the unchanged tuned
    `bn_addmul_1_f12` primitive in the same order and at the same result
    offsets; and
  - the result header publishes positive size twenty-three when limb
    twenty-three is zero, otherwise positive size twenty-four.

This is an exact outer-leaf port. Allocation, row sequencing, offsets, and
publication move to native Tungsten; the fixed C row primitives remain the
arithmetic kernel. The arm requires two distinct heap BigInts with raw
positive twelve-limb headers. Pointer identity remains the existing square
route; signs and neighboring widths retain their former routes. A genuine
open-world BigInt `*` reopen remains observable.
