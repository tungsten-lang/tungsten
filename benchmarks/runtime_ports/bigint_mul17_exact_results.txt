BIGINT POSITIVE SEVENTEEN-BY-SEVENTEEN-LIMB MULTIPLY — EXACT SOURCE CHECKPOINT
================================================================================

Scope
-----

This checkpoint ports only the distinct, raw-positive-header, positive
seventeen-by-seventeen-limb arm from `bigint_mul_any_routed` /
`bigint_mul_positive_equal`. Native Tungsten preserves C's exact
`bn_mul_eq17` decomposition:

  - the same capacity-sixty-four hot allocation;
  - row zero calls the unchanged tuned `bn_mul_1_f17` primitive;
  - rows one through sixteen call the unchanged tuned
    `bn_addmul_1_f17` primitive in the same order and at the same result
    offsets; and
  - the result header publishes positive size thirty-three when limb
    thirty-three is zero, otherwise positive size thirty-four.

This is an exact outer-leaf port. Allocation, fixed-kernel selection, row
sequencing, offsets, and publication move to native Tungsten; the fixed C
kernel and row primitives remain the arithmetic implementation. The arm
requires two distinct heap BigInts with raw positive seventeen-limb headers.
Pointer identity remains the existing square route; signs and neighboring
widths retain their former routes. A genuine open-world BigInt `*` reopen
remains observable.
