BIGINT POSITIVE ONE-LIMB MULTIPLY — EXACT SOURCE CHECKPOINT
==========================================================

Scope
-----

This checkpoint ports the distinct positive heap-BigInt 1-by-1 arm from
`bigint_mul_positive_11` without changing its algorithm or result policy.
Native Tungsten loads both limbs and performs the same unsigned 64-by-64
multiply. The retained raw finisher preserves C exactly:

  high == 0  -> bigint_finish_one_limb(low, positive)
  high != 0  -> exact hot capacity 2; limbs [low, high]; signed size +2

The finisher is force-inlined because the corresponding C leaf is inlined in
`w_mul`. Pointer-identical squaring, signed one-limb pairs, and every wider
N-by-1 arm remain on their existing C paths. A dynamic route bit is carried
only by the public operator call; internal runtime multiplication always
passes zero, so a user BigInt `*` reopen cannot leak into internal arithmetic.

This is the exact-port checkpoint. It contains no native-only arithmetic or
dispatch redesign.
