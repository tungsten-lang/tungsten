BIGINT POSITIVE TWO-LIMB BY ONE-LIMB MULTIPLY — EXACT SOURCE CHECKPOINT
========================================================================

Scope
-----

This checkpoint ports the distinct positive heap-BigInt 2-by-1 arm from
`bigint_mul_n1_tiny` without changing its arithmetic, allocation class, or
result policy. Native Tungsten allocates the same hot capacity-4 result,
loads the same two source limbs, issues both unsigned 64-by-64 products, and
settles them with the same one-bit carry chain. The raw finisher publishes
signed size +2 or +3 exactly as C does.

The public seam preserves receiver order so a plain BigInt `*` reopen keeps
normal open-world precedence. Only distinct positive 2-by-1 and 1-by-2 heap
shapes are admitted. Pointer-identical squaring, signs, 1-by-1, every other
N-by-1 width, and internal runtime multiplication keep their existing paths.
The width check precedes the source-route check so neighboring widths do not
take a route-dependent branch.

This is the exact-port checkpoint. It contains no native-only arithmetic,
closed-world dispatch, or lifecycle redesign.
