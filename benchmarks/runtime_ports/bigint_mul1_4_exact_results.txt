BIGINT POSITIVE FOUR-LIMB BY ONE-LIMB MULTIPLY — EXACT SOURCE CHECKPOINT
============================================================================

Scope
-----

This checkpoint ports only the distinct positive heap-BigInt 4-by-1 arm from
`bigint_mul_n1_small`. It preserves the current production C implementation:
the hot capacity-8 allocation; the linked AArch64 mul/umulh/add-with-carry
instruction order; unconditional fifth-limb write; and exact positive size
+4/+5 publication. It does not substitute `bigint_mul_n1_tiny`'s separately
tuned independent-product schedule.

The public seam preserves receiver order so an open-world BigInt `*` reopen
retains normal precedence. Only distinct positive 4-by-1 and 1-by-4 heap
shapes are admitted. Pointer-identical squaring, signs, widths 1..3, and every
wider scalar-word shape keep their existing routes.

This is the exact-port checkpoint. It contains no native-only dispatch,
carry-chain, allocation, or lifecycle redesign.
