BIGINT POSITIVE TWENTY-ONE-BY-TWENTY-ONE-LIMB MULTIPLY — EXACT SOURCE CHECKPOINT
=================================================================================

Scope
-----

This checkpoint ports only the distinct, raw-positive-header, positive
twenty-one-by-twenty-one-limb arm from `bigint_mul_any_routed` /
`bigint_mul_positive_equal`. Native Tungsten preserves C's exact
`bn_mul_eq21` decomposition:

  - the same capacity-sixty-four hot allocation;
  - row zero calls the unchanged generic `bn_mul_1` primitive with length
    twenty-one;
  - rows one through twenty call the unchanged tuned `bn_addmul_1_f21`
    primitive in the same order and at the same result offsets; and
  - the result header publishes positive size forty-one when limb forty-one
    is zero, otherwise positive size forty-two.

This is an exact outer-leaf port. Allocation, fixed-kernel selection, row
sequencing, offsets, and publication move to native Tungsten; the fixed C
kernel and row primitives remain the arithmetic implementation. The arm
requires two distinct heap BigInts with raw positive twenty-one-limb headers.
Pointer identity remains the existing square route; signs and neighboring
widths retain their former routes. A genuine open-world BigInt `*` reopen
remains observable.
