BIGINT POSITIVE FIVE-BY-FIVE-LIMB MULTIPLY — EXACT SOURCE CHECKPOINT
==================================================================

Scope
-----

This checkpoint ports only the distinct, raw-positive-header, positive
five-by-five-limb arm from `bigint_mul_any_routed` /
`bigint_mul_positive_equal`. Native Tungsten preserves C's exact generic
schoolbook decomposition:

  - the same capacity-sixteen hot allocation;
  - row zero calls the unchanged tuned `bn_mul_1(n=5)` C primitive;
  - rows one through four call the unchanged tuned `bn_addmul_1(n=5)` C
    primitive in the same order and at the same result offsets; and
  - the result header publishes positive size nine when limb nine is zero,
    otherwise positive size ten.

This is an exact outer-schoolbook port, not a flattened or approximate
replacement. Allocation, row sequencing, offsets, and publication move to
native Tungsten; the five deliberately tuned row primitives remain C. The
runtime admits the arm only after proving two distinct heap BigInts with raw
positive five-limb headers. Pointer identity remains `sqr@5`; signs and every
neighboring width remain on their existing paths. A genuine open-world
BigInt `*` reopen remains observable.
