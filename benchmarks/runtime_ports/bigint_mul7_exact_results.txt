BIGINT POSITIVE SEVEN-BY-SEVEN-LIMB MULTIPLY — EXACT SOURCE CHECKPOINT
====================================================================

Scope
-----

This checkpoint ports only the distinct, raw-positive-header, positive
seven-by-seven-limb arm from `bigint_mul_any_routed` /
`bigint_mul_positive_equal`. Native Tungsten preserves C's exact generic
schoolbook decomposition:

  - the same capacity-sixteen hot allocation;
  - row zero calls the unchanged tuned `bn_mul_1(n=7)` C primitive;
  - rows one through six call the unchanged tuned `bn_addmul_1(n=7)` C
    primitive in the same order and at the same result offsets; and
  - the result header publishes positive size thirteen when limb thirteen is
    zero, otherwise positive size fourteen.

This is an exact outer-schoolbook port. Allocation, row sequencing, offsets,
and publication move to native Tungsten; the seven tuned row primitives
remain C. The arm requires two distinct heap BigInts with raw positive
seven-limb headers. Pointer identity remains `sqr@7`; signs and neighboring
widths retain their former routes. A genuine open-world BigInt `*` reopen
remains observable.
