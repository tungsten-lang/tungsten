BIGINT POSITIVE SIXTEEN-LIMB SQUARE — EXACT SOURCE CHECKPOINT
=======================================================================

Scope
-----

This checkpoint ports only the pointer-identical, raw-positive-header,
positive sixteen-limb arm from `bigint_mul_any_routed`. Native Tungsten
preserves C's exact outer shape:

  - the same capacity-thirty-two hot allocation;
  - one call to the unchanged `bn_sqr16_split` kernel; and
  - positive size thirty-one when limb thirty-one is zero, otherwise size
    thirty-two.

The split-square arithmetic is deliberately unchanged. Allocation, the
dedicated seam, and result publication move to native Tungsten; the already
tuned C kernel remains the exact arithmetic leaf. Tag-overlay negatives with
a positive raw header remain admitted. True negative headers, distinct-equal
boxes, and every neighboring width retain their former routes. A genuine
open-world BigInt `*` reopen remains observable.
