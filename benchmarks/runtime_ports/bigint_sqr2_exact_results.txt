BIGINT POSITIVE TWO-LIMB SQUARE — EXACT SOURCE CHECKPOINT
========================================================

Scope
-----

This checkpoint ports only the pointer-identical, raw-positive-header,
two-limb arm from `bigint_mul_any_routed` / `bigint_mul_positive_equal`.
The native Tungsten worker is a literal copy of the current AArch64 leaf:

  - exact hot capacity-4 allocation;
  - low square, doubled cross product, high square;
  - the same `mul` / `umulh` / `extr` and flag-chain order;
  - four unconditional limb stores;
  - positive size 3 when limb 3 is zero, otherwise positive size 4.

The stable seam is dedicated to `sqr@2`; it does not reuse any scalar-word
contract. A tag-overlay negative with raw header +2 is admitted just as in C,
while a real negative header and all wider squares retain their old C routes.
A plain open-world BigInt `*` replacement still wins over the narrow seam.

allocation/shape-dispatch frame.
