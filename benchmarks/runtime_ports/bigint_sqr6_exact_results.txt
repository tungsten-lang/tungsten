BIGINT POSITIVE SIX-LIMB SQUARE — EXACT SOURCE CHECKPOINT
=========================================================

Scope
-----

This checkpoint ports only the pointer-identical, raw-positive-header,
six-limb arm from `bigint_mul_any_routed` / `bigint_mul_positive_equal`.
The native Tungsten worker is a literal copy of the release/LTO AArch64
`bn_sqr6` leaf:

  - exact hot capacity-16 allocation for the twelve-limb result;
  - the same six diagonal and fifteen doubled cross products;
  - the same fixed, intentionally noinline `mul` / `umulh` / `extr` /
    flag-chain schedule;
  - twelve unconditional limb stores; and
  - positive size 11 when limb 11 is zero, otherwise positive size 12.

The dedicated stable seam admits the same tag-overlay negative with raw header
+6 as C. A real negative header, distinct equal boxes, and every neighboring
width retain their existing routes. A plain open-world BigInt `*` reopen
remains observable.

The benchmark compiler disables the committed closed-world square shortcut
(`TUNGSTEN_BIGINT_MUL_LOCKED_DIRECT=0`) so ordinary source `a * a` reaches
this checkpoint. The runtime toggle `TUNGSTEN_BIGINT_SRC_OPS=0` pins the same
binary to C. Extending the locked native switch to sqr@6 is deliberately
deferred to the separate native-only tranche.
