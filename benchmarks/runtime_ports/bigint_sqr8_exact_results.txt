BIGINT POSITIVE EIGHT-LIMB SQUARE — EXACT SOURCE CHECKPOINT
===========================================================

Scope
-----

This checkpoint ports only the pointer-identical, raw-positive-header,
eight-limb arm from `bigint_mul_any_routed` / `bigint_mul_positive_equal`.
The native Tungsten worker is a literal copy of the release/LTO AArch64
`bn_sqr8_inline` schedule:

  - exact hot capacity-16 allocation for the sixteen-limb result;
  - the same eight diagonal and twenty-eight doubled cross products;
  - the same always-inlined `mul` / `umulh` / `extr` / flag-chain schedule;
  - sixteen unconditional limb stores; and
  - positive size 15 when limb 15 is zero, otherwise positive size 16.

The dedicated stable seam admits the same tag-overlay negative with raw header
+8 as C. A real negative header, distinct equal boxes, and every neighboring
width retain their existing routes. A plain open-world BigInt `*` reopen
remains observable.

The benchmark compiler disables the committed closed-world square shortcut
(`TUNGSTEN_BIGINT_MUL_LOCKED_DIRECT=0`) so ordinary source `a * a` reaches
this checkpoint. The runtime toggle `TUNGSTEN_BIGINT_SRC_OPS=0` pins the same
binary to C. Native-only closed-world integration remains a separate measured
tranche after the exact-port series.
