DESIGN

The exact arithmetic checkpoint stays unchanged.  The runtime's existing
positive one-limb shape proof now distinguishes that leaf from the general
source arm and enters `__w_bigint_sub1_1_src`.  The strong Core wrapper tail-
calls `__bigint_sub1_1_raw`; its linked AArch64 body is exactly two limb loads,
`subs`, `cneg`, signed-size materialization, and a tail branch to the retained
finisher.  C-only/stage-0 links retain a weak definition calling the identical
C leaf.  The weak seam latch keeps non-LTO C-only steady state inline.

Emitter selection preserves open-world semantics: if a program supplies a
plain BigInt `-` reopen, the narrow and complete minus seams both target that
last definition.  Protected/locked Core programs reject such a reopen before
lowering.
