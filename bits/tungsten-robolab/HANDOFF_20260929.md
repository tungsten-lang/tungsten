## 5. Rules and traps

- The arena rules are in `playground/arena/README.md`. Never change an existing trial's seeds, env or metric: make a new trial.
  Edit `playground/arena/champions.json` and `playground/arena/history.jsonl` only under `arena.locked()` (`playground/arena/.lock`).
- Evaluate a copy of your binary. A promotion freezes whatever the path holds at the end of the run.
- Deterministic trials promote on any strict gain; stochastic ones need p < 0.05 on the paired sign-flip test, whose smallest possible
  p is 2^-k for k differing starts. Give a trial enough starts for the gain you care about (that is why the 48-start run trials exist).
- Failed guards and crashes score plus or minus 1e9. `arena.py board` shows the mean over the passing rollouts beside the pass count;
  never read `summary.mean` of a trial with failures directly.
- Label ceiling-class controllers ORACLE in the note (open-loop programs that bypass the contraction-target plus reflex layer).
- Bodies: v2, v3 (tendons), p50 and p95 profiles, elite (unverified magnitudes, provisional), elite2 (literature), v4 (calibrated: quadriceps series
  stiffness 250 to 1000 N/mm, hip speeds 15 to 18.5 and 29 rad/s; `ROBOLAB_CALIB=v4`). Mark results by body. The old 10.2 m/s ceiling was invalid
  (it used an ideal torso stabiliser).
- The checkout is shared with other sessions that commit to `main`. Never `git add` a directory or use the shared index for robolab files;
  use `tools/snapshot_commit.sh` (plumbing onto a side branch).
- The machine is loaded (load average about 50 on 18 cores at 01:15). Wall times run 2 to 3 times slower than in the logs; simulation results are unaffected.
  Use at most 3 or 4 workers per search.
- A worktree build sees the shared checkout's sources unless `BIT_HOME` is set: Erik's `~/.zshrc` exports `BIT_HOME=$HOME/tungsten/bits`, and `use robolab/...` resolves through it before the worktree's own `bits/`.
  Verify from a worktree with `export BIT_HOME=<worktree>/bits` and check that no `build/cache/irbin-*.manifest` names `/Users/erik/tungsten/bits/tungsten-robolab/lib` (the 9/29 landings were first verified without this).
- `playground/search.py` writes the best params to `--out` on every improvement; resume with `--init`. A search's `--fixed` values lose to `--init`'s for the same names.

## 7. Committing and landing

`tools/snapshot_commit.sh` builds a commit of everything under `bits/tungsten-robolab` with a temporary index (files over 2 MB, compiled scratch
binaries, scratch media and the arena lock excluded; the practice logs under `params/search_logs` and `playground/search_results` are force-added because
Erik's global `~/.gitignore` drops `*.log`) and moves only the branch `robolab-campaign-2026-09` with a compare-and-swap. It does not touch HEAD,
the shared index or the working tree, and it never pushes. Commit only when Erik has asked. While agents are mid-edit in `lib/` and `playground/`, use
`tools/snapshot_commit.sh --only <paths...>` for a partial snapshot of safe files (docs, tools, arena data, logs) so unverified sources do not ride along.

`tools/land_snapshot.sh` lands the branch on `main`: a fast-forward when `main` has not moved, otherwise a merge commit from `git merge-tree` (it refuses on
conflicts), then a compare-and-swap `update-ref`, then `git reset -q -- bits/tungsten-robolab` so the shared index describes the new `main` for those paths only.
`--dry-run` shows the plan. Land only when Erik says so, and only a snapshot that has been verified (the 29 Sep landing was checked from a fresh worktree first).

For a verified PARTIAL landing while other agents are mid-edit (the 29 Sep pattern): the side branch is a backup that may hold unverified work, so build the landing commit on a
temporary branch cut from `main`: `git branch -f robolab-land-tmp main`, then, holding the arena lock (`fcntl.flock` on `playground/arena/.lock`),
`tools/snapshot_commit.sh --branch robolab-land-tmp --only <the finished agents' paths> playground/arena <docs>`; verify that exact commit from a fresh worktree
(build the changed entries, replay their champions with `--controller bin/robolab_<entry>` and no `--promote`, the SDK spec, the compiler front end on every entry when
shared SDK code changed); then `tools/land_snapshot.sh --branch robolab-land-tmp` and delete the temporary branch. Full snapshots in `--only`-less mode also work now that
tracked-but-ignored `*.log` files are added with `-f`.

Editing an old note in `playground/arena/history.jsonl` (done once, for the two bat entries): take the `fcntl` lock on `playground/arena/.lock`, replace the text on exactly those
lines, check that every parsed record differs only in `note`, and `os.replace` the file.
