The local v93 baseline timed out at 60 seconds on the 540-variable stable-extension instance (2ca47af4ab7a). The later Wassat release built from fff0e7c9 produced an independently checked SAT assignment in 0.039 seconds. Stedman, knight-tour and three-cubes controls also produced checked models. Its 267,297 negative binary clauses connecting variables 1–10,000 to the next 10,000 encode a very different search problem from choosing a stable set in a fixed graph. Before porting a graph walk, test counter and guarded-support recognition on this formula.
