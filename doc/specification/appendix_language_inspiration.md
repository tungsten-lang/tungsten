# Appendix B: Language inspiration

This appendix is informative. It acknowledges Tungsten's language-design
heritage; it does not make compatibility claims or add normative semantics.

Tungsten combines ideas from object-oriented, functional, systems, scripting,
and concurrent languages. The introduction's shorthand describes it as
"ruby-colored" and "coffee-flavored," with references to Elixir, Scala, F#,
C#, Crystal, Fancy, Perl, and Potion. Those names are acknowledgements, not a
claim that Tungsten copies any one language's grammar, object model, type
system, or runtime.

The normative definition of Tungsten is the main body of this specification.
Where a familiar-looking construct differs from another language, Tungsten's
lexical, grammar, semantics, and object-model chapters are authoritative.
